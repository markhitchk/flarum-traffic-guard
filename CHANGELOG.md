# Changelog

## 1.0.0-dev - 2026-08-09

Initial development build:

- Flarum 1.8.x backend middleware for forum/API/admin stacks
- Manual IPv4/IPv6 and CIDR allow/block rules
- Country, ASN, path, and user-agent rules
- Optional VPN/proxy/Tor/hosting/risk detection through proxycheck.io
- Threat-result caching and configurable failure behavior
- Admin rule manager, detection settings, custom block pages, logs, and test tools
- Trusted reverse-proxy client-IP resolution
- Custom HTML response templates and safe preview
- Access logging with configurable IP privacy mode and retention
- CLI enable/disable/unban/status/prune recovery commands
